# SocialPro Automation Backend

هذا المشروع يوفر هيكلية أولية لنظام أتمتة حملات تيليجرام كما هو موصوف في المستند،
مع واجهة API مبنية باستخدام FastAPI وقاعدة بيانات SQLite لتتبع الحسابات،
الوظائف (Jobs) وسجلات العمليات.

## المتطلبات

- Python 3.10 أو أحدث
- أدوات Poetry أو pip لتثبيت الاعتماديات من `pyproject.toml`

## التثبيت والتشغيل

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
uvicorn app.main:app --reload
```

سيتم إنشاء قاعدة البيانات داخل مجلد `data/` بالإضافة إلى المجلدات التالية:

- `data/groups` لتخزين ملفات نتائج البحث عن المجموعات
- `data/members` لملفات الأعضاء المستخرجة
- `data/prepared` للقوائم المعالجة
- `data/sessions` لملفات جلسات Telethon المشفرة

## الواجهات الرئيسية

- `POST /accounts` لتسجيل حسابات تيليجرام مع تشفير api_id و api_hash
- `POST /groups/search` لبدء عملية البحث عن مجموعات بناءً على كلمات مفتاحية وتخزين النتيجة
- `POST /members/extract` لاستخراج أعضاء من المجموعات وحفظهم في ملف CSV
- `POST /members/prepare` لتنقية قوائم الأعضاء وإنتاج ملفات مقسمة قابلة لإعادة الاستخدام
- `POST /members/add` لمحاكاة إضافة الأعضاء لمجموعة معينة مع احترام حدود السرعة
- `POST /members/message` لإرسال رسائل مخصصة لقوائم الأعضاء
- `GET /jobs` و `GET /jobs/{id}` لمتابعة حالة العمليات وحجم التقدم

تنفذ الخدمات الحالية منطقًا محاكيًا (Mocked) للتفاعل مع تيليجرام حتى يتم ربطها
فعليًا بمكتبة Telethon/Pyrogram لاحقًا. الهيكلية توفر طبقات واضحة لإضافة
إدارة معدلات الإرسال، التعامل مع الأخطاء، والتوسع عبر Workers حقيقية.

## ملاحظات أمنية

- يتم توليد مفتاح تشفير وتخزينه في `data/.fernet.key` لتشفير بيانات API الحساسة.
- تأكد من حماية هذا المجلد وضبط الأذونات بشكل مناسب في بيئات الإنتاج.

## الخطوات التالية المقترحة

- ربط الخدمات مع Telethon الحقيقية وواجهات تسجيل الدخول للتحقق من الحسابات.
- إضافة نظام طوابير (Celery/Redis) لتوزيع الوظائف الثقيلة وعدم حظر واجهة API.
- بناء لوحة تحكم أمامية (React/Tailwind) لعرض الحسابات، العمليات، والسجلات التفاعلية.
- تحسين استراتيجيات إعادة المحاولة وإدخال نظام التنبيهات كما هو موصوف في المتطلبات.
